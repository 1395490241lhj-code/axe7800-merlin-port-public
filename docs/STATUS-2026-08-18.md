## What "crossed" does and does not mean

It means the build stage completes. Where a produced binary is reported as matching stock, that
is a **build/copy** comparison by hash.

Explicitly **not** established:

- runtime ABI compatibility
- flash safety
- install-stage compatibility for the SYSSTATE and LIBBCM inputs (not yet tested — no build has
  reached the install stage)
- wireless runtime compatibility
